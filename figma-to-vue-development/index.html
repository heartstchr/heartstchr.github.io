Frequently Asked Questions

Do you work with Figma only, or other design tools?

Figma is my primary tool, but I can also work with Sketch, Adobe XD, or even well-organized design specs. Figma's developer handoff features make it the most efficient option.

Can you also handle the backend and API integration?

Yes. I am a full-stack developer. The frontend can be built independently from the Figma file, and I can also build the backend, APIs, and database layer.

Do you use a component library or build from scratch?

I use PrimeVue or Tailwind CSS as a foundation, then build custom components to match your Figma exactly. This gives you the speed of a library with the fidelity of a custom build.

How do you handle animations and micro-interactions?

Vue's transition system combined with CSS animations or libraries like GSAP for complex scroll-based effects. I match the timing curves and easing from your Figma prototype.
