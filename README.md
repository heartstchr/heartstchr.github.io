# Jiwan Ghosal Portfolio Website (Stack Seekers)

## 🎯 Project Purpose

This is a professional portfolio website for **Jiwan Ghosal**, a full-stack freelance developer operating under the brand "Stack Seekers". The site serves as both a personal portfolio and a business website to showcase services and attract clients.

## 🏗️ Technical Architecture

- **Framework:** VuePress 2.0 (static site generator)
- **Theme:** VuePress Theme Hope 2.0
- **UI Framework:** PrimeVue 4.3.3 with Aura theme
- **Styling:** PrimeFlex 3.3.1 (utility-first CSS)
- **Build Tool:** Vite 6.3.2
- **Language:** TypeScript + JavaScript

## 📁 Content Structure

- **Homepage:** Hero, testimonials, services overview
- **About:** Personal background, tech stack, certifications
- **Services:** 7 offerings (Web Dev, E-commerce, API, Figma-to-Web, Consulting, CI/CD, Hosting)
- **Portfolio:** 20+ project showcases (SaaS, dashboards, widgets, etc.)
- **Blog:** 12+ technical articles (Vue, web dev, AI, etc.)
- **Media:** YouTube videos, podcast

## 🎨 Design & UX

- Modern, responsive UI with PrimeVue components
- Dark mode, mobile-first, clean typography
- Interactive elements: testimonials carousel, project gallery, service tabs, contact forms, video embeds

## 🔧 Development Features

- **Build & Deploy:** GitHub Actions, pre-build scripts, SEO, performance optimizations
- **Custom Components:** ProjectCard, BlogList, Contact, YouTubePlayers, CustomButton, etc.
- **Content Management:** Centralized data, dynamic content, Markdown frontmatter, SEO meta

## 🚀 Business Model

- **Services:** Full-stack dev, consulting, design-to-code, e-commerce, API
- **Audience:** Startups, enterprises, agencies, small businesses

## 📈 Key Strengths

- Professional presentation, comprehensive portfolio, technical depth
- Content marketing (blog, video), client testimonials, SEO optimized
- Mobile responsive, business-focused

## 🎯 Unique Value Proposition

"Stack Seekers" is a full-stack development partner specializing in MERN/MEVN stacks, helping startups and businesses turn ideas into powerful digital products. The portfolio demonstrates both technical capability and business understanding.
